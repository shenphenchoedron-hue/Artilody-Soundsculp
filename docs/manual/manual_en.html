1. Introduction

Artilody Soundsculp is a program for editing and combining several audio tracks. Every audio file you open becomes a track. All tracks are shown below each other on a shared timeline and play together. The audio on a track lives in clips, which can be split, moved around – also to other tracks – and joined again, much like in Audacity.

Features: trim, cut/copy/paste, split and join clips, fade in and out, normalize, silence trim, loop, reverse, pitch shifting without changing the speed, a parametric EQ, a noise remover, a volume line on every track, coloured markers, recording from a microphone, merging tracks, and export to WAV, AIFF, FLAC and Ogg Vorbis.

The program is in English. A Danish interface can be chosen under Settings (gear) → Language (requires a restart).

Every change can be undone. The original file is never modified – the result is only written when you export.

2. Installation

Download the installer from the Releases page at github.com/shenphenchoedron-hue/Artilody-Soundsculp.

Windows (10 and 11)

  1. Download ArtilodySoundsculp-1.1.3-Windows-Setup.exe and double-click it.
  2. If Windows SmartScreen shows "Windows protected your PC", click More info → Run anyway.
  3. Follow the wizard. The program and the manuals are then in the Start menu.

A Portable zip is also available – unpack it and run the program without installing.

macOS (11 or newer, Intel and Apple Silicon)

  1. Download ArtilodySoundsculp-1.1.3-macOS-Universal.dmg, open it and drag the program to Applications.
  2. The first time (the app is not notarised): on macOS 15 Sequoia or newer, try to open the app once, then open System Settings → Privacy & Security and click Open Anyway next to the message about Artilody Soundsculp. On macOS 11–14 you can instead right-click the app, choose Open and confirm. Alternatively type in Terminal: xattr -dr com.apple.quarantine "/Applications/Artilody Soundsculp.app"
  3. The first time you record, macOS asks for microphone access – answer OK.

Debian (12+) and Ubuntu (22.04 / 24.04)

Download the .deb file for your system and install it, for example:

sudo apt install ./artilody-soundsculp_1.1.3_debian-12_amd64.deb

The program is in the application menu under Sound & Video, or start it with artilody-soundsculp. The package is self-contained – everything the program needs is included, nothing else has to be downloaded. Uninstall with sudo apt remove artilody-soundsculp.

4. Tracks: open, create and merge

Opening audio files

Click Open file in the top bar or Open above the track list (Ctrl+O). You can select several files at once or drag files into the window. Each file becomes a new track at the bottom. Formats: WAV, AIFF, FLAC, Ogg Vorbis and MP3 on all systems; on macOS also M4A/AAC and CAF. Opus files cannot be opened.

Selecting a track

Click a track to select it (its header turns blue). Editing, effects and markers work on the selected track. Double-click the header to rename the track, click × to close it.

New empty track and inserting audio

+ → New empty track (Ctrl+N) creates an empty track. Click a position on it and:

  • insert an audio file with + → Insert audio file at cursor…, or
  • copy a piece from another track (Ctrl+C), click the position and paste (Ctrl+V), or
  • drag a clip from another track onto it (see section 5).

Different sample rates or channel counts are converted automatically.

Merging tracks into a new track

Click Merge above the track list (or + → Merge tracks into one track…). Tick the tracks to include and press Merge. The tracks are mixed into a new track called "Merged track". Volume lines are included and become part of the audio, so the new track starts with a flat volume line. Markers are copied. If the mix gets too loud, the level is reduced automatically. Optionally tick Close the merged tracks afterwards.

5. Clips – audio in pieces

The audio on a track lives in clips. Each clip has a dark-blue name bar at the top. Between clips there can be empty gaps (darker area), which play as silence.

  • Cut (Ctrl+X) and Delete remove the selection and leave a gap – the track does not close up.
  • Delete and close gap (Shift+Delete) removes the selection and closes the gap.
  • Split (Ctrl+I) splits the clip at the cursor – or at the selection edges.
  • Join (Ctrl+J) joins the clips in the selection into one clip; gaps become silence.
  • Move a clip: drag its name bar left or right. Clips cannot overlap – if you drop a clip onto another, it snaps next to it.
  • Move a clip to another track: drag the name bar up or down. The track you drop on lights up green.
  • Click the name bar to select the whole clip.
  • Right-click in the audio for a menu with Cut, Copy, Paste, Delete, Delete and close gap, Split here, Join clips, Select clip and Rename clip.

Paste (Ctrl+V) inserts a new clip at the cursor. If the cursor is inside a clip, the clip is split and the rest is pushed to the right. In a gap, later audio is only pushed if there is not enough room. If there is a selection, it is replaced.

6. Selecting with the mouse

  • Drag in the audio to select (turns purple). Drag the white handles to adjust. Shift+click extends.
  • A single click sets the cursor (white line) – also after the end of the audio or in a gap.
  • Double-click selects the part between two markers. Ctrl+A selects the whole track.
  • Click in the time ruler to move the cursor.

7. Editing

Effects work on the selection – or on the whole track if nothing is selected. They work on all clips inside the selection.

ButtonFunction
Trim (Ctrl+T)Keeps only the selection. It stays where it is (like Audacity).

Split / JoinSplit and join clips (see section 5).
Fade In / Fade OutSmooth fade over the selection (without a selection: the first/last 3 seconds). Follows time, so it is smooth across several clips.
NormalizeRaises/lowers the level so the loudest peak is at −0.1 dB.

ReverseReverses the audio.

8. Pitch

Click Pitch and choose between −12 and +12 semitones. Preview listens (up to 10 s), Apply keeps the change. Length and tempo are preserved.

9. Parametric EQ

4 bands with type (Low Shelf, Bell, High Shelf, Low Cut, High Cut, Notch), frequency, gain, Q and on/off.

  • Drag the coloured points in the curve (horizontal = frequency, vertical = gain). The mouse wheel changes Q, double-click resets.
  • The drop-down has presets (Bass boost, Vocal presence, Warmth, Remove rumble, Telephone …).
  • The switch at the top right lets you hear the EQ live during playback.
  • Apply applies the EQ permanently to the selection or track. Then turn the switch off.

10. Noise Remover

  1. Select a part with only noise and choose … → Learn noise profile from selection (otherwise the noise is estimated automatically).
  2. Select what to clean (or nothing for the whole track).
  3. Adjust Reduction, Sensitivity and Artifact Control. The spectrum shows original (grey) and filtered (cyan).
  4. Preview listens (up to 15 s); the headphones button lets you hear only the noise being removed. Press Apply.

11. The volume line

Each track has an orange volume line that controls the level over time without changing the audio itself. It is used for playback, merging and export.

  • Choose the Volume tool and click to add points; drag them up and down. The middle is 0 dB, the top +6 dB, the bottom silence.
  • With Select you can drag existing points and double-click the line to add new ones.
  • Right-click a point to delete it. File panel → … → Reset volume line removes all points.
  • The volume line belongs to the track timeline – if you move a clip, the line stays where it is.

12. Markers

Each track has its own markers with its own numbering (marker 1 on one track has nothing to do with marker 1 on another).

  • Click on the marker line below a track to add a marker. Type its text in the Markers panel on the left and press Enter. The panel shows which track the markers belong to.
  • Below the track only the marker number is shown; the text is in the panel and appears when you hover over the marker.
  • Colour: click the coloured triangle in the Markers panel – or right-click the marker and choose Change colour…. Pick one of the 12 preset colours or any other colour.
  • Drag a marker to move it. Right-click to rename, change colour, select to the next marker or delete.
  • + in the panel (or M) adds a marker at the cursor – also during playback.

14. Zoom and track height

  • The zoom bar above the tracks: Zoom out, Zoom in, Zoom to selection and Show all, plus the zoom percentage.
  • On the right of the bar: Track height – makes the tracks lower or taller.
  • With the mouse: Ctrl+wheel zooms at the mouse, Shift+wheel scrolls sideways, Alt+wheel changes the track height, the wheel alone scrolls up/down through the tracks.
  • The keys +, − and 0 (show all) and the sliders in the top bar and status bar also work.

15. Export

Click Export (Ctrl+E). In the window you choose:

  • What to export: Current track, Selection only or All tracks mixed (all tracks in one file – muted tracks are left out, solo tracks win).
  • Format: WAV (16-bit, 24-bit or 32-bit float), AIFF (24-bit), FLAC (16-bit or 24-bit, lossless) or Ogg Vorbis (192 kbps, compressed).
  • File name and Folder (with Choose…). The file extension follows the format automatically.

The info line shows length, sample rate, stereo/mono and the approximate file size. Volume lines are always included. The program remembers the last format and folder. If the file exists, you are asked before it is replaced.

16. Undo and settings

  • Undo/Redo: the arrow buttons or Ctrl+Z / Ctrl+Y. Each track has its own history.
  • Settings (gear): Audio settings, Language (English/Danish – restart), Keyboard shortcuts and About.

18. Troubleshooting

  • No sound: check the output device under Settings → Audio settings, and that the tracks are not muted (M).
  • Recording does not work: choose an input device in Audio settings. On macOS allow microphone access in System Settings → Privacy & Security → Microphone.
  • A file cannot be opened: Opus files are not supported, and M4A/AAC files can only be opened on macOS. Convert the file to WAV or FLAC with another program first.
  • macOS says the app is damaged: run xattr -cr "/Applications/Artilody Soundsculp.app" in Terminal.
