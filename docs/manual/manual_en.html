1. Introduction

Artilody Soundsculp is a simple audio editor. You can open several audio files at once (each file becomes a track), create empty tracks, cut and copy audio between tracks, improve the sound with effects and finally export a single track or all tracks mixed into one file.

Features: mouse selection, trim, cut/copy/paste, fade in and out, normalize, silence trim, loop, reverse, pitch shifting without changing the speed, a parametric EQ, a noise remover, a volume line on every track, text markers, recording from a microphone, and export to WAV, FLAC, MP3, OGG, AIFF, M4A and Opus.

Every change can be undone. The original file is never modified – the result is only written when you export.

2. Installation

Download the installer from the Releases page at github.com/shenphenchoedron-hue/Artilody-Soundsculp.

Windows (10 and 11)

  1. Download ArtilodySoundsculp-1.0.0-Windows-Setup.exe.
  2. Double-click it. If Windows SmartScreen shows "Windows protected your PC", click More info and then Run anyway.
  3. Follow the wizard. The program and the manuals are then available in the Start menu.

A Portable zip is also available – unpack it and run the program without installing.

macOS (11 or newer, Intel and Apple Silicon)

  1. Download ArtilodySoundsculp-1.0.0-macOS-Universal.dmg and open it.
  2. Drag Artilody Soundsculp into the Applications folder.
  3. The first time: right-click (or ctrl-click) the app, choose Open and confirm with Open. The app is not notarised by Apple, so macOS asks once. If that does not help, open Terminal and type: xattr -cr "/Applications/Artilody Soundsculp.app"
  4. The first time you record, macOS asks for microphone access – answer OK.

Debian (12+) and Ubuntu (22.04 / 24.04)

Download the .deb file for your system (debian-12 or ubuntu-22.04-24.04) and install it with:

sudo apt install ./artilody-soundsculp_1.0.0_debian-12_amd64.deb

The program then appears in the application menu under Sound & Video, or start it with the command artilody-soundsculp. The package recommends ffmpeg, which is used for MP3, M4A and Opus export. If it was not installed automatically: sudo apt install ffmpeg.

Uninstall with sudo apt remove artilody-soundsculp.

4. Tracks: open, create, insert and merge

Opening audio files

Click + (in the top bar or the Tracks panel) and choose Open audio files… (Ctrl+O). You can select several files at once, or drag files into the window. Each file opens as a new track.

Supported formats: WAV, AIFF, FLAC, OGG, MP3 – and with ffmpeg also M4A/AAC, Opus, WMA and more.

New empty track

Choose + → New empty track (Ctrl+N). An empty track shows 30 seconds so you can click a position. Then you can:

  • Insert an audio file: + → Insert audio file at cursor…. The file is inserted where you clicked.
  • Copy a piece from another track: select the other track, select an area, press Copy (Ctrl+C), select the empty track, click the position and press Paste (Ctrl+V).

If you click after the end of the audio, the gap is filled with silence automatically. Different sample rates or channel counts are converted automatically.

Merging tracks into one track

Choose + → Merge tracks into one track…. Tick the tracks to include and press Merge. The tracks are mixed together (all starting at 0:00) into a new track called "Merged track". Volume lines are included and markers are copied. If the mix gets too loud, the level is reduced automatically to avoid clipping. Optionally tick Close the merged tracks afterwards.

If you just want all tracks in one file, use Export → All tracks mixed into one file (see section 13). Turn on Play all tracks in the status bar to hear the mix first.

Other track functions

The tracks menu also has Duplicate track, Rename track… and Close track.

5. Selecting with the mouse

  • Drag in the waveform to select. The selection turns purple.
  • Drag the white handles at the edges to adjust start and end. Shift+click extends the selection.
  • A single click removes the selection and sets the cursor (the white line).
  • Double-click selects the part between two markers – for example a whole verse.
  • Ctrl+A selects the whole track. Click in the time ruler to move the cursor.

Start, end and length are shown in the top bar and the status bar.

Most effects work on the selection. With nothing selected they work on the whole track.

7. Pitch

Click Pitch. Choose between −12 and +12 semitones (in steps of 0.1). The −12, −1, +1, +12 buttons give quick choices. Press Preview to listen (up to 10 seconds) and Apply to keep the change. Length and tempo are preserved.

8. Parametric EQ

The EQ has 4 bands. Each band has a type (Low Shelf, Bell, High Shelf, Low Cut, High Cut, Notch), frequency, gain (dB), Q (width) and an on/off button.

  • Drag the coloured points in the curve: horizontal = frequency, vertical = gain. The mouse wheel over a point changes Q. Double-click resets the gain.
  • Values can also be changed by dragging the fields, or double-clicking and typing a value.
  • The drop-down at the top has presets (Bass boost, Vocal presence, Warmth, Remove rumble, Telephone …).
  • The switch at the top right lets you hear the EQ live during playback.
  • Apply applies the EQ permanently to the selection (or the whole track). Then turn the switch off so you do not hear it twice.

9. Noise Remover

The noise remover reduces constant background noise (hiss, hum, fans).

  1. For the best result: select a part containing only noise and choose … → Learn noise profile from selection. The switch turns on. Without a learned profile the noise is estimated automatically.
  2. Select what to clean (or nothing for the whole track).
  3. Adjust Reduction (how much the noise is reduced), Sensitivity (how much is treated as noise) and Artifact Control (smoothing against "watery" sound).
  4. The spectrum shows the original (grey) and the filtered result (cyan). Press Preview to listen (up to 15 s). The headphones button lets you hear only the noise being removed.
  5. Press Apply.

10. The volume line

Each track has an orange volume line that controls the level over time without changing the audio itself. It is used for playback, merging and export.

  • Choose the Volume tool and click on the waveform to add points. Drag points up and down (and sideways). The middle is 0 dB (unchanged), the top is +6 dB and the bottom is silence. The value is shown while dragging.
  • With the Select tool you can still drag existing points, and double-click the line to add new ones.
  • Right-click a point to delete it. File panel → … → Reset volume line removes all points.

11. Text markers

Markers show, for example, where a verse or chorus starts.

  • Click on the marker line below the waveform to add a marker. The text field in the Markers panel on the left becomes active – type the text (e.g. "Verse 1") and press Enter.
  • The marker is shown as a coloured label on the marker line, a triangle on the time ruler and a thin line through the waveform.
  • Drag a marker to move it. Right-click to rename, select to the next marker or delete.
  • + in the Markers panel (or the M key) adds a marker at the cursor – also during playback.
  • Click a marker in the list to jump to it. × deletes the marker.

13. Export

Click Export (Ctrl+E) and choose what to export:

  • Current track – the whole selected track.
  • Selection only – only the selected area.
  • All tracks mixed into one file – all tracks combined.

Then choose the format and file name. The volume line is always included.

FormatNote
WAV 16 / 24 / 32-bit floatUncompressed, best quality.
AIFF 24-bitUncompressed (popular on Mac).
FLAC 16 / 24-bitLossless compression.
OGG Vorbis 192 kbpsCompressed.
MP3 320 / 192 kbpsCompressed – needs ffmpeg*.
M4A / AAC 256 kbps, Apple LosslessNeeds ffmpeg*.
Opus 160 kbpsNeeds ffmpeg*.

* ffmpeg is included with the Windows and macOS installers. On Linux install it with sudo apt install ffmpeg.

14. Undo, zoom and settings

  • Undo/Redo: the arrow buttons or Ctrl+Z / Ctrl+Y. Each track has its own history.
  • Zoom: the magnifiers, the slider, +/−, 0 (whole track) or Ctrl+mouse wheel. The mouse wheel alone scrolls sideways. Click/drag in the overview to move the view.
  • Settings (gear): Audio settings, Language (English/Danish – requires restart), Keyboard shortcuts and About.

16. Troubleshooting

  • No sound: check the output device under Settings → Audio settings.
  • Recording does not work: choose an input device and enable input channels in Audio settings. On macOS allow microphone access under System Settings → Privacy & Security → Microphone.
  • MP3/M4A/Opus is greyed out: ffmpeg was not found. Install ffmpeg (Linux: sudo apt install ffmpeg, macOS: brew install ffmpeg).
  • A file cannot be opened: the format may require ffmpeg (e.g. M4A on Linux).
  • macOS says the app is damaged: run xattr -cr "/Applications/Artilody Soundsculp.app" in Terminal.
